# Documentation Archive

This directory contains completed, superseded, or historical implementation
plans. These files explain how the system evolved, but they are not normative
and may contain paths, commands, ports, or behavior that no longer exist.

Use [the documentation index](../INDEX.md) for current architecture,
configuration, operations, API, testing, and extension guidance.

## Contents

- Root files in this directory are older project-wide specifications.
- [`root/`](root/) contains plans and reviews moved from the repository root
  during the August 2026 documentation cleanup.
- Generated reference material remains outside the archive and is explicitly
  labeled in the current documentation index.

Historical records should receive only link repairs or archival labels. New
requirements and decisions belong in the active numbered documentation or an
architecture decision record.
