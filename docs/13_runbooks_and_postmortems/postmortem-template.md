# Postmortem Template

> Standard format for documenting incidents after resolution. Copy this template for each incident.

---

```markdown
# Postmortem: [Brief Title]

## Date: YYYY-MM-DD
## Duration: HH:MM - HH:MM (X hours)
## Severity: P1/P2/P3/P4

## Impact
- What was affected (positions, balance, missed trades)
- Financial impact (if any)

## Timeline
- HH:MM — First symptom observed
- HH:MM — Root cause identified
- HH:MM — Mitigation applied
- HH:MM — Full resolution confirmed

## Root Cause
- Technical explanation of why it happened
- What went wrong in the system

## Resolution
- What was done to fix it
- Immediate actions taken

## Lessons Learned
- What we learned from this incident
- What worked well in the response
- What could have been done better

## Action Items
- [ ] Action 1 — [owner] — [deadline]
- [ ] Action 2 — [owner] — [deadline]
- [ ] Update runbook with new diagnostic steps
- [ ] Add monitoring for early detection
```
