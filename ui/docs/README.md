# UI Documentation Status

This directory contains the original Figma delivery notes and task-by-task UI
implementation records. `TASK_*`, visual-reference files, and
`PROJECT_COMPLETE.md` are historical snapshots from February 2026 and may
describe removed features or superseded ports.

Use these current sources instead:

- [`ui/README.md`](../README.md) for development commands
- [`docs/10_frontend_dashboard/`](../../docs/10_frontend_dashboard/) for
  architecture, charts, and UI configuration
- [`docs/14_api_reference/`](../../docs/14_api_reference/) for backend contracts
- [`Guidelines.md`](Guidelines.md) for contribution rules
- [`Attributions.md`](Attributions.md) for third-party design assets

Historical files should not be used as acceptance criteria for new work.
